INTRODUCTION					     *translator-introduction*

	This plugin translates visually selected text using `translate-shell`
	as the backend engine. 

	The plugin automatically detects the translation direction by scanning
	the visual selection for Cyrillic characters. If Russian text is found,
	it translates `ru:en`. Otherwise, it defaults to `en:ru`.

	You can find the `translate-shell` utility at:
	Homepage: https://www.soimort.org/translate-shell/
	Clone:    git clone https://github.com/soimort/translate-shell.git
==============================================================================
USAGE							    *translator-usage*

	Highlight text in |Visual-mode| and press the translation hotkey
	(Default: <leader>t, see |g:translator_hotkey|). 

	The translated text is displayed directly in the command-line area with
	custom highlights, without leaving any temporary messages behind.

CONFIGURATION					    *translator-configuration*

	You can configure the plugin by setting the variables below in
	your |vimrc|.

	Note on syntax:
	If your |vimrc| starts with `vim9script`, use the direct assignment
	syntax as shown in the examples (e.g., g:translator_hotkey = ...).
	For legacy Vimscript, prepend each variable definition with the `let`
	command (e.g., let g:translator_hotkey = ...).
------------------------------------------------------------------------------
|g:loaded_translator| (Default: 0)			 *g:loaded_translator*
	To disable the plugin, set this variable to 1: >
		g:loaded_translator = 1
------------------------------------------------------------------------------
|g:translator_hotkey| (Default: <leader>t)		 *g:translator_hotkey*
	Keyboard shortcut to invoke the translator: >
		g:translator_hotkey = '<leader>t'
------------------------------------------------------------------------------
|g:translator_copy_to_clipboard| (Default: 0)   *g:translator_copy_to_clipboard*
	Copy the translated text to the system clipboard. Vim must be compiled
	with the |+clipboard| or |+xterm_clipboard| feature. To enable copying,
	set the variable to 1: >
		g:translator_copy_to_clipboard = 1
------------------------------------------------------------------------------
|g:translator_color_translated_text|	  *g:translator_color_translated_text*
	Foreground color of the translated text output.
	Default: White
	Possible values: Black, DarkBlue, DarkGreen, DarkCyan, DarkRed,
			 DarkMagenta, DarkYellow, DarkGray, Gray, Blue,
			 Green, Cyan, Red, Magenta, Yellow, White, NONE
>
		g:translator_color_translated_text = 'DarkGreen'
------------------------------------------------------------------------------
|g:translator_bgcolor_translated_text|    *g:translator_bgcolor_translated_text*
	Background color of the translated text output.
	Default: Black
	Possible values: Black, DarkBlue, DarkGreen, DarkCyan, DarkRed,
			 DarkMagenta, DarkYellow, DarkGray, Gray, Blue,
			 Green, Cyan, Red, Magenta, Yellow, White, NONE
>
		g:translator_bgcolor_translated_text = 'Black'

MAPPINGS						 *translator-mappings*

	<leader>t - Translate the selected text
		    (direction detected automatically)

	To change the keyboard shortcut, see |g:translator_hotkey|.
